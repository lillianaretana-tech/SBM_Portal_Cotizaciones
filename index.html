Movimientos registrados

Consultar y comprobar cotizaciones históricas · V27

Consulta un registro existente sin modificarlo. Los Excel de consecutivos y extraordinarios son reportes oficiales consolidados, no el archivo individual COM-F-04/06. Descarga el reporte correspondiente y usa Excel para imprimirlo a PDF. No se fabrica una cotización individual a partir de datos incompletos.

Selecciona un registro para consultar sus datos.

La ficha imprimible es solo para comprobación interna; no reemplaza la presentación comercial de Excel. Para obtener el PDF oficial, abre el Excel original y utiliza su configuración de impresión. La consulta no altera ningún registro.

Generar documentos oficiales

Se utilizan como base los Excel oficiales que acabas de entregar. Los movimientos nuevos se insertan únicamente en filas disponibles. Las hojas de enero a septiembre de 2026 permanecen sin cambios.

Antes de enviar, verifica montos, aprobación, embarcado/pendiente y fórmulas en Excel. No se sustituye ningún registro base; las discrepancias detectadas requieren revisión humana.
